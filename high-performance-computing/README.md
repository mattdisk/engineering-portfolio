# High-Performance Computing

Parallel algorithms and synchronization for shared-memory, distributed-memory, and GPU execution, with attention to communication and memory-hierarchy costs.

**Skills demonstrated:** C with OpenMP, MPI, and CUDA; barrier and collective-communication algorithms; cache-oblivious design; scaling experiments on a Slurm cluster.

| Project | Summary | Source |
|---|---|---|
| [openmp-mpi-barriers](openmp-mpi-barriers.md) | Sense-reversing, tournament, dissemination, and MCS-style barrier algorithms in OpenMP, MPI, and a hybrid MPI/OpenMP form, with scaling experiments. | Available on request |
| [high-performance-algorithms](high-performance-algorithms.md) | Parallel list ranking (OpenMP, CUDA), MPI collectives built from point-to-point messages, a TeraSort-style distributed sort, and a cache-oblivious funnel sort. | Available on request |
