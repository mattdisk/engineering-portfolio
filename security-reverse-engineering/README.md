# Security & Reverse Engineering

Low-level security work on native binaries: designing an exploitation challenge, developing exploits across vulnerability classes and architectures, and building program-analysis tools for malware.

**Skills demonstrated:** x86/x86-64/ARM/RISC-V reverse engineering, exploit development (shellcode, ROP, heap), GDB, Ghidra scripting, Intel Pin instrumentation, and pwntools.

| Project | Summary | Source |
|---|---|---|
| [toupper-pwn](toupper-pwn.md) | 32-bit Linux binary-exploitation challenge designed and built for a CTF competition, with containerized deployment and a reference exploit. | [github.com/mattdisk/toupper-pwn](https://github.com/mattdisk/toupper-pwn) |
| [catch_the_flag](catch_the_flag.md) | Exploit development across x86, x86-64, ARM, and RISC-V targets: reverse engineering, shellcode, ROP, format-string, heap, and logic and race-condition vulnerabilities. | Available on request |
| [malware-program-analysis](malware-program-analysis.md) | Static (Ghidra, P-code) and dynamic (Intel Pin, NetworkX) analysis tools that produce control-flow, data-dependence, and control-dependence graphs for a Windows malware sample. | Available on request |
